Diffie–Hellman key exchange is a cryptographic algorithm used to securely exchange a secret key between two parties over a public network. It allows two users to create the same secret key without actually sending the key to each other. Its purpose is:Secure key exchange,Safe communication over the internet It is not mainly used for encryption itself.
